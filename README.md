# Kaaviya Murugesan | Throwball

Personal athlete website for Kaaviya Murugesan, throwball player representing the USA Women's National Team.

## Files
- `index.html`: main page (story, tournaments, awards, gallery, sponsorship, contact)
- `videos.html`: videos page

Both pages are self-contained (photos and videos are embedded), so there is no build step. Open `index.html` in a browser.

## Publish with GitHub Pages
Repository **Settings > Pages > Deploy from a branch > main > / (root)**. The site will be live at `https://kaaviya-2006.github.io/kaaviya_throwball_website/`.
